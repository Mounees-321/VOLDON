📦 VOLDON – Volunteer Donation Platform

A mobile application built using Flutter + Firebase that connects Donors, Volunteers, and Receivers to simplify donation management, tracking, and delivery.

✅ Features
👤 User Roles

Donor – Upload donation items (food, clothes, etc.)

Volunteer – Accept and deliver donations to receivers

Receiver – Request and receive items

📱 App Features

User authentication using Firebase Auth

Store data with Cloud Firestore

Upload and fetch images from Firebase Storage

Real-time status updates

Location-based matching (optional)

Simple, clean UI with roles and dashboards

🚀 Getting Started
1. Clone the repo
git clone https://github.com/your-username/VOLDON.git
cd VOLDON

2. Install dependencies
flutter pub get

3. Add Firebase configuration

Place your google-services.json in:

android/app/

4. Run the app
flutter run
